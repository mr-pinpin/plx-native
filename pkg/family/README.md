# MrPomPom application icon

This newly generated icon was commissioned for the user's native MrPomPom
family application. Mama, older PinPin and baby MrPomPom appear as a close family
group. The master is an unaltered built-in imagegen PNG; application sizes use
RGB Lanczos resizing only. `provenance.json` records the exact prompt, reference
hashes and output hashes. Reference sheets and book artwork are not included.

Files are `mrpompom-family-icon-master-v1.png` and
`mrpompom-family-icon-{80,130,160,256,320,400}-v1.png`.

The launcher packages byte-identical 80px and 130px exports as `icon.png` and
`largeIcon.png`. The master and all named exports remain in the
[canonical source icon directory](https://github.com/mr-pinpin/mr-pinpin-source/tree/fix/family-native-tv/apps/family-native/icon).
The provenance hashes refer to those original export names.
