# v0.9.1 — Account-free home media for PinPin

This PinPin fork adds an explicitly configured local-server mode for a household Plex Media Server. It opens the existing native interface without Plex account linking or QR onboarding; the ordinary account flow remains available when local configuration is absent.

## What's new

- **Open your home library directly.** A private device configuration selects the household server without inventing account credentials or tokens.
- **Follow the server on the home network.** Background discovery accepts only the configured server identity and keeps the interface responsive.
- **No external telemetry account needed.** This fork's release builds explicitly disable external telemetry while retaining the package and source verification gates.

## Compatibility

The local-server candidate is awaiting verification on an LG OLED55A3RLA running webOS 10.3.2. Server access and discovery have been checked from that TV, but this is not yet a playback claim for the modified ARM application or other models.

## Installing

Download **com.beb.plxnative_0.9.1_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). The private setup and the server-side access requirement are described in [local server setup](https://github.com/mr-pinpin/plx-native/blob/release/v0.9/docs/local-server.md).

Nothing in this distribution chain is signed, so verify the download against this checksum:

```
__IPK_SHA256__  com.beb.plxnative_0.9.1_arm.ipk
```

[Installing and checking a download](https://github.com/mr-pinpin/plx-native/blob/release/v0.9/docs/install-and-verify.md) explains package verification and Developer Mode renewal. This package bundles FFmpeg under LGPL-2.1-or-later; its complete corresponding source accompanies the release. The [technical audit](https://github.com/mr-pinpin/plx-native/blob/release/v0.9/docs/release-audits/v0.9.1.md) distinguishes checks from device evidence.
