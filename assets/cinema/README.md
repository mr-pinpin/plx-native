# Cinema artwork

These are newly generated Cinema application assets commissioned by the user:
Mr PinPin eating popcorn against a navy background. The selected masters are
unaltered PNG outputs from the built-in image generation tool. Application-size
exports use RGB Lanczos resizing only. The original generated splash is
1672 × 941; its television export is 1920 × 1080. No painting or compositing was
used for these exports.

`provenance.json` records the exact prompts, references, source hashes, selected
outputs, export dimensions and output hashes. The book character sheet supplied
identity guidance; the book miniature supplied rendering guidance. Neither book
reference image is included in this directory or in the application package.

## Files

- `cinema-icon-master-v1.png`: selected original 1254 × 1254 icon.
- `cinema-icon-{80,130,160,256,320,400}-v1.png`: application-size exports.
- `cinema-splash-master-v1.png`: selected original generated splash.
- `cinema-splash-1920x1080-v1.png`: television splash export.

The icon is opaque and contains no text. The splash contains only the word
“Cinema”. Dark margins leave room for the operating system's clipping and TV
safe areas.
